# Kanban

A Trello-style board built on Baseplate: email and password login, boards with lists and cards, drag to move a card, and row-level security that keeps every board private to the person who made it.

It exists to prove the whole path works, so nothing here is mocked.

## Run it

From this directory:

```bash
npx @diepen/baseplate init --port 8090 --postgres-port 5490 --dashboard-port 8790
npx @diepen/baseplate up
npm install
```

The schema is drizzle's, so push it and then hand the tables to Baseplate:

```bash
npm run db:push
npx @diepen/baseplate schema adopt-table boards
npx @diepen/baseplate schema adopt-table lists
npx @diepen/baseplate schema adopt-table cards
npm run db:types
npm run dev
```

Open http://127.0.0.1:5273, create an account, and make a board.
Create a second account and it sees none of the first one's boards.

## Why adopt

`drizzle-kit push` creates tables, and a table Baseplate did not create is locked down until it is told about it: row-level security on, every grant revoked.
That is the safe default, and it means a table cannot appear on the API by accident.

`schema adopt-table` is how you hand one over. In a single transaction it records the table, writes the access policy, adds the trigger that stamps `owner_id` from the caller's token, and grants the app role.

Adopt again after adding a table. Existing tables are unaffected.

## What the app never does

It never sends `owner_id`. The database sets it from the `sub` of the caller's token, so a client cannot claim a row belongs to someone else.

It never filters by user. `select()` returns what that caller is allowed to see, because the filtering is a policy in Postgres rather than a `where` clause the client could forget.

There is no anon key and no public key. `JWT_SECRET` stays on the server.

## Layout

| Path | What it is |
| --- | --- |
| `db/schema.ts` | The drizzle schema: boards, lists, cards, with cascades |
| `drizzle.config.ts` | Points drizzle at the database in `baseplate.env` |
| `src/client.ts` | The typed Baseplate client |
| `src/database.ts` | Generated by `baseplate types`; regenerate after a schema change |
| `src/features/` | Sign in, boards, one board, one list |
| `src/position.ts` | Where a card sits, as a number between its neighbours |
